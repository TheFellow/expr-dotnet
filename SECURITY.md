# Security Policy

Expr.NET is intended to evaluate untrusted expressions against host-controlled
environments. Security reports should not be opened as public issues.

Report suspected vulnerabilities privately through GitHub Security Advisories
for this repository. Include the expression, environment shape, observed
behavior, expected behavior, and the Expr.NET version or commit.

Until a stable release is published, no version is considered security-supported.

The implementation's trust boundaries, required controls, and release gate are
documented in the [security model](docs/security-model.md).
